# Rewards Tracker PWA

Includes points tracking, configurable daily goal, local transaction history, offline support, and puzzle-piece rewards. Award one puzzle piece manually for each activity completed for seven consecutive days. Track pieces separately from the points balance. Every 12 pieces represents a projected 1,000-point bonus, which is included in the estimated completion time. The estimate uses an editable weekly piece pace (default: 3 pieces/week, matching the three weekly activities shown in the supplied screenshot); it does not automatically add bonus points to the balance. Data is stored locally in this browser/device.

Deploy all files to the root of your GitHub Pages branch. After publishing, reload the installed app while online to receive the update.
