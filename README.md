# Rewards Tracker — Android PWA

A mobile-first, offline-capable tracker for Microsoft Rewards points toward an Xbox gift card.

## Features

- Track current points balance and editable target
- Manually add earned points or set the total balance
- Configurable daily earning target and optional daily goal
- Today's earnings and estimated days remaining
- Daily transaction history
- Local browser storage and offline support
- Installable on Android through Chrome

## Install on Android

1. Enable GitHub Pages for this repository using the `main` branch and `/(root)` folder.
2. Open the published HTTPS site in Chrome on Android.
3. Open Chrome's menu and choose **Install app** or **Add to Home screen**.
4. Launch Rewards Tracker from your home screen.

Data is stored locally on the device/browser. Clearing site storage will erase the locally saved tracker data. No Microsoft account connection or API access is required.
